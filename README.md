# Лабораторная работа: JWT и цифровая подпись

Авторизация добавлена непосредственно в `src/Lab5WordSignature.java`.
Теперь программа не создаёт и не подписывает документ, пока пользователь не
пройдёт регистрацию и вход.

## Как работает программа

1. Пользователь регистрируется. Пароль сохраняется в памяти как PBKDF2-хеш с солью.
2. Пользователь входит по логину и паролю.
3. Программа создаёт JWT с алгоритмом `HS256` и сроком действия 15 минут.
4. JWT проверяется: формат, алгоритм, HMAC-подпись, срок действия и наличие пользователя.
5. Только после успешной проверки запускается исходная лабораторная работа RSA:
   создаётся `input.docx`, вычисляется хеш, формируется цифровая подпись и выполняются
   проверки изменённых документов.

Пользователи хранятся только в памяти, поэтому после перезапуска их нужно
зарегистрировать заново.

## Запуск из IntelliJ IDEA

Запустите `main` в файле `src/Lab5WordSignature.java`.

## Запуск из консоли

Проект использует Apache POI для работы с `.docx`, поэтому в IntelliJ IDEA должны
быть подключены библиотеки из проекта.

Секрет JWT можно заменить через переменную окружения `JWT_SECRET`. Если переменная
не задана, используется учебный секрет из исходного файла.

JWT состоит из трёх частей:

```text
header.payload.signature
```

Payload токена можно прочитать, поэтому в него нельзя помещать пароль. Защиту от
подделки обеспечивает подпись `HMAC-SHA256`.
