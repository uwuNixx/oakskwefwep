# JWT-авторизация

В проект добавлен простой пример авторизации на Java без внешних библиотек —
`src/JwtAuthorization.java`.

Программа умеет:

1. зарегистрировать пользователя;
2. сохранить пароль в виде PBKDF2-хеша с солью;
3. выполнить вход и выдать JWT с алгоритмом `HS256`;
4. проверить подпись JWT, пользователя и срок действия токена;
5. открыть защищённый ресурс только с корректным токеном;
6. показать три части токена: `header.payload.signature`.

Пользователи хранятся в памяти, поэтому после перезапуска программы их нужно
зарегистрировать заново. Это учебный пример, а не готовая production-система.

## Запуск из IntelliJ IDEA

Откройте файл `src/JwtAuthorization.java` и запустите метод `main`.

## Запуск из консоли

Из корня проекта:

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/JwtAuthorization.java
java -cp out JwtAuthorization
```

Для собственного секрета подписи можно задать переменную окружения:

```bash
JWT_SECRET="длинная случайная строка" java -cp out JwtAuthorization
```

В JWT нельзя хранить пароль или другие секреты: payload токена кодируется
Base64 и читается любым пользователем. Защиту обеспечивает именно подпись
`HMAC-SHA256`, а пароль проверяется отдельно по PBKDF2-хешу.
